# LostMemory ComfyUI 게임 아이콘 생성 가이드

## 문서 목적

ComfyUI + Tailscale + EC2 nginx로 구성된 사내 이미지 생성 환경에서, 게임에 바로 쓸 수 있는 픽셀 아트 아이콘/스킬 아이콘을 만드는 절차를 정리한다. 다음 세션이나 새 팀원이 1분 안에 따라할 수 있게 한다.

## 전체 그림

```
프롬프트 또는 레퍼런스
  → ComfyUI (운영 PC, RTX 4050)에서 512×512 일러스트풍 생성
  → pixelize.py로 게임 톤(48 또는 64 + 게임 32색 + 투명배경) 양자화
  → Unity Assets/_Project/Art/ 에 import
```

## 4. 가장 자주 쓸 시나리오

### 시나리오 A. 텍스트만으로 새 아이템 생성

1. 브라우저로 `https://lostmemory.duckdns.org` 접속, Basic Auth 로그인
2. 좌측 사이드바 **Workflows → LostMemory_Item_TXT2IMG** 클릭
3. 노드 4 (긍정 프롬프트)에서 `< ITEM HERE >` 부분만 교체

   ```text
   a single red health potion bottle with glowing liquid,
   cork stopper, label tag
   ```

4. **Queue Prompt** (`Ctrl+Enter`). 30~60초 소요
5. 결과는 운영 PC의 `tools/ComfyUI/output/LostMemory_Item_*.png`
6. 운영 PC 명령 한 줄로 게임 톤 양자화

   ```text
   pixelize-game-item32.cmd <파일경로>   ← 일반 아이템 32×32
   pixelize-game-item48.cmd <파일경로>   ← 특수 아이템 48×48
   ```

7. `tools/ComfyUI/output_pixel/<파일>_native32.png` 또는 `_native48.png`를 Unity `Assets/_Project/Art/Icons/`에 import

### 시나리오 B. 기존 자산을 게임 톤으로 변환만

```text
pixelize-game-item48.cmd <기존 PNG 경로>
```

디자인은 그대로 두고 32색 게임 팔레트만 강제 적용. 투명배경 유지.

### 시나리오 C. 기존 자산을 AI로 변형

1. 원본 PNG를 운영 PC `tools/ComfyUI/input/`에 복사 (가능하면 512×512로 미리 nearest 다운스케일)
2. 브라우저에서 **LostMemory_Item_IMG2IMG** 워크플로 로드
3. 노드 20 (LoadImage)에서 그 파일 선택
4. 노드 4 프롬프트 작성
5. 노드 6 (KSampler) `denoise` 조정

   - 0.3 ~ 0.5 = 원본 거의 유지, 색감 또는 디테일만 변경
   - 0.5 ~ 0.7 = 구도 유지, 내용 변경 (권장)
   - 0.8 이상 = 거의 새로 생성, 레퍼런스는 약하게만 참고

6. Queue Prompt → 결과 → `pixelize-game-item32.cmd` 또는 `pixelize-game-item48.cmd`

## 5. 프롬프트 패턴

### 일반 아이템 (포션, 책, 음식 등)

```text
Pixel art game icon style. a single < ITEM HERE >,
isolated, centered, plain white background,
clean black outline, simple flat shading,
muted vintage colors with subtle red and pink accents,
no gradient, no anti-aliasing, sharp pixel edges,
game inventory icon
```

`< ITEM HERE >` 예시

- `red health potion bottle`
- `golden brass key with ornate handle`
- `blue sapphire gem`
- `leather bound spellbook`
- `roasted chicken leg`

### 효과가 있는 아이템 (전기/불/얼음/마법)

```text
... a single <기본 아이템>,
<BRIGHT 색 EFFECT TYPE> <위치 또는 움직임>,             ← 핵심 1
crackling <동의어> <명사>,                              ← 핵심 2
<jagged|glowing|swirling> <효과> shapes,                ← 핵심 3
glowing <효과> aura, <분위기 ing> energy field,         ← 핵심 4
vibrant <색> <효과>, ...
```

핵심은 효과를 3~4번 다른 단어로 반복하고, 중요 키워드는 ALL CAPS로 강조하고, negative에는 "평범한 버전"을 넣어 차단하는 것이다.

### 부정 프롬프트 (기본값)

```text
realistic, 3d render, photo, smooth shading, anti-aliased,
blurry, gradient, detailed background, noisy background,
text, watermark, low quality, multiple objects, cluster, deformed
```

효과 아이템이면 추가로

```text
plain glasses, normal glasses, calm, peaceful
```

같이 평범 버전을 직접 차단.

| 항목 | 값 |

## 7. 게임 아이콘 표준 사이즈

| 카테고리 | 사이즈 | 용도 |
| --- | --- | --- |
| 일반 인벤토리 아이템 | 32×32 | `식품-`, `악세-`, `장난감-`, `의약품-` 등 대부분 |
| 특수 아이템 | 48×48 | `48.48 ~` 프리픽스 (물약, 커피, 카메라 등) |
| 스킬 아이콘 | 48×48 또는 64×64 | 효과가 많으면 64×64 권장 |
| UI 아이콘 | 13×13 ~ 16×16 | lock, unlock 같은 미세 UI |

16×16 캐릭터 스프라이트는 AI 직접 생성이 어렵다. 컨셉만 AI로 만들고 Aseprite로 손으로 도트하는 하이브리드를 추천.

## 8. 팀 공유 방식

### PNG 직접 공유

ComfyUI가 생성한 PNG에는 워크플로 메타데이터가 박혀 있다. 그 PNG를 다른 ComfyUI 화면에 드래그앤드롭하면 노드 그래프와 프롬프트가 100% 동일하게 복원된다. 슬랙으로 PNG를 보내면 받는 사람이 그대로 재현 가능하다.

### History 패널

같은 ComfyUI 서버를 쓰는 팀원끼리는 좌측 사이드바 **Queue** 또는 **History** 패널에서 최근 실행 기록을 공유한다. 클릭 한 번으로 그 워크플로를 가져온다.

### Git 추적 위치

자주 쓸 워크플로는 `tools/docs/workflows/`에 .json 형태로 커밋한다. 새 PC에서도 그 .json을 ComfyUI에 드래그하면 재현 가능.

## 9. 함정 정리 (운영 중 실제 경험)

| 증상 | 원인 / 해결 |
| --- | --- |
| 전기 효과가 사라짐 | 프롬프트가 약함. ALL CAPS로 4번 다른 표현 반복 + negative에 "plain ..." 명시 |
| img2img 결과가 원본 그대로 | denoise 너무 낮음. 0.4 → 0.6 |
| img2img 결과가 완전 다름 | denoise 너무 높음. 0.7 → 0.5 |
| Queue Prompt 누르고 0%에서 멈춤 | 첫 모델 로딩 30~60초. 그냥 기다리기 |
| OOM | 6 GB VRAM 한계. width/height 768 이하 |
| 결과가 흐림/평범 일러스트 | LoRA 미적용. `LoraLoader strength_model=0.85` 권장 |
| 502/504 Bad Gateway | 운영 PC가 꺼졌거나 ComfyUI 죽음. `start_comfyui.cmd` 재실행 |
| nginx 401 | Basic Auth 자격 입력 필요. 브라우저 시크릿 창 또는 재로그인 |
| 워크플로 JSON 수정 시 "Return type mismatch between linked nodes" | link ID 중복 또는 노드 inputs link 값 불일치. `validate_workflow.py`로 사전 검증 |
