# 2차 MVP 작업표

## 문서 목적

- 2차 MVP backlog를 1차와 분리해서 관리할 준비 폴더다.
- img2img, 도트 화풍 변환, 프로젝트 전용 LoRA, 운영 고도화 같은 후순위 작업을 이 폴더로 모은다.

## 현재 상태

- 아직 2차 backlog CSV는 만들지 않았다.
- 1차 MVP의 최소 동작 범위를 먼저 닫은 뒤 이 폴더에 작업표를 추가한다.

## 후보 범위

- 도트 이미지 -> 원하는 화풍 img2img
- 공개 LoRA 비교와 기준 화풍 정리
- 프로젝트 전용 LoRA 학습
- workflow 공유 확장 기능
