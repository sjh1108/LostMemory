## 지금까지 해본 것

### 1. 로컬 운영 기준

- ComfyUI 실행 위치는 `tools/ComfyUI`로 고정
- 로컬 실행은 `.venv_local` 기준
- 모델/LoRA 파일은 저장소에 직접 커밋하지 않고 로컬 경로에만 배치
- 생성 실험 결과와 운영 판단만 `tools/docs`에 정리

### 2. 공개 LoRA 실험 대상

| 구분 | 대상 | 용도 | 메모 |
|---|---|---|---|
| 기본 모델 | `Tongyi-MAI/Z-Image-Turbo` | 빠른 생성, 프롬프트 테스트 | 로컬 ComfyUI 실험용 |
| 공개 LoRA 1 | `tarn59/pixel_art_style_lora_z_image_turbo` | pixel art 스타일 비교 | 트리거: `Pixel art style.` |
| 공개 LoRA 2 | `reverentelusarca/elusarca-pixel-art-style-lora-zimage-turbo` | 다른 pixel art 감도 비교 | 프롬프트에 `pixel art` 사용 |

### 3. 실험에서 본 포인트

- 캐릭터:
  - 전신 비율과 장비/의상 유지 정도
  - 머리, 얼굴, 실루엣이 얼마나 일관적으로 나오는지
- 타일:
  - 반복 배치했을 때 경계가 튀는지
  - 탑다운 시점과 패턴 규칙이 유지되는지
- 오브젝트:
  - 중앙 정렬이 되는지
  - 작은 크기로 줄여도 실루엣이 읽히는지

### 4. 현재 판단

- 공개 LoRA는 빠르게 화풍 감을 잡는 데는 유용하다.
- 다만 프로젝트 전용 화풍을 오래 유지하기에는 한계가 있다.
- 캐릭터, 타일, 오브젝트는 요구 규칙이 달라서 결국 분리 학습이 필요하다.
- 따라서 공개 LoRA 비교는 baseline 확보 단계로 보고, 최종 방향은 프로젝트 전용 LoRA로 가져가는 편이 맞다.

## 이제 새로 할 것

### 1. 모델 역할 분리

- 로컬 / ComfyUI 직접 생성과 테스트:
  - `Z-Image-Turbo`
- 서버 / 프로젝트 전용 LoRA 학습:
  - `Z-Image`

이렇게 나누는 이유는 간단하다.

- `Z-Image-Turbo`는 빠른 생성과 프롬프트 실험에 유리하다.
- `Z-Image`는 프로젝트 전용 스타일을 묶는 학습 베이스로 보는 편이 안정적이다.

### 2. 프로젝트 전용 LoRA 목표

- `myproj_char_v1`
  - 캐릭터 비율, 얼굴, 의상, 포즈 일관성
- `myproj_tile_v1`
  - seamless 타일, 경계 연결, 탑다운 규칙
- `myproj_object_v1`
  - 중앙 정렬, 아이템 실루엣, 단일 오브젝트 가독성

### 3. 데이터셋 구조 초안

```text
datasets/
  char_v1/
    train/
    val/
  tile_v1/
    train/
    val/
  object_v1/
    train/
    val/
```

운영 원칙:

- 캐릭터, 타일, 오브젝트는 절대 한 폴더에 섞지 않는다.
- 각 이미지에는 캡션 텍스트를 짝으로 둔다.
- 스프라이트 시트는 잘라서 단일 에셋 단위로 분리한다.
- 업스케일은 `nearest-neighbor` 기준으로 맞춘다.

### 4. 당장 할 일

1. `tools/ComfyUI/models/loras`에 공개 LoRA를 반입해 비교 실험 기준을 고정한다.
2. 캐릭터, 타일, 오브젝트 프롬프트를 최소 20장씩 생성해 baseline을 만든다.
3. 어떤 결과가 괜찮았는지 프롬프트와 seed를 같이 기록한다.
4. 프로젝트 데이터셋을 `char / tile / object`로 나눠 정리한다.
5. 서버 학습은 `Z-Image` 기준으로 `myproj_char_v1`부터 먼저 시작한다.

## 운영 원칙

- 실제 모델 파일과 LoRA 가중치는 Git에 직접 올리지 않는다.
- 저장소 문서에는 모델명, 경로 규칙, 실험 메모, 다음 액션만 남긴다.
- public LoRA와 프로젝트 LoRA는 같은 `models/loras` 폴더를 쓰더라도 문서에서 출처를 분리해 적는다.
- 팀 문서 기준 최신본은 항상 `tools/docs`에만 둔다.
