# 1차 MVP 작업표

## 문서 목적

- 1차 MVP backlog 관련 원본 작업표를 한 폴더에서 보게 한다.
- `생성 -> 저장 -> 조회` 최소 흐름을 닫는 작업만 이 폴더에서 관리한다.

- 메인 source of truth는 `컴피유아이-1차-mvp-통합-작업표.csv`
