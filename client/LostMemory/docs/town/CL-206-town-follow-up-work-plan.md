- 담당 기준: 클라2

## 업무 파악

현재 작업은 마을씬을 새로 만드는 작업이 아니다. 이미 존재하는 간단한 마을씬을 기준으로, MVP1에서 필요한 최소 기능과 귀환 흐름을 붙이는 후속 작업이다.

핵심 흐름은 다음과 같다.

```text
기존 마을씬 점검
-> 마을 레이아웃, 시작 위치, 카메라, 충돌 보강
-> 던전/스테이지 이동 트리거 배치
-> 전투/던전 종료 후 마을 귀환 위치 연동
-> UI, NPC 자리, 사운드 등 MVP 최소 상태 정리
-> 통합 테스트
```

이번 범위에서는 정식 마을 콘텐츠를 완성하기보다, 플레이어가 마을에서 시작하고 던전으로 이동한 뒤 다시 마을로 돌아오는 흐름이 안정적으로 동작하는 것을 우선한다.

## 작업 계획

### 1. 현황 파악

기존 마을씬의 Hierarchy, 배치된 오브젝트, 플레이어 시작 지점, 카메라 구성, Collider, UI 노출 상태를 먼저 확인한다. 이 단계에서는 씬을 바로 고치기보다 현재 상태와 부족한 부분을 메모한다.

확인 항목:

- 마을씬 파일 위치와 씬 이름
- 플레이어 프리팹 또는 시작 오브젝트 존재 여부
- Spawn Point 존재 여부
- 카메라 Follow, Confiner, Boundary 설정 여부
- 건물, 장식물, 맵 경계 Collider 여부
- 던전 또는 스테이지 이동 트리거 존재 여부
- 마을 진입 시 전투 UI가 노출되는지 여부

### 2. 보강 범위 확정

MVP1에서 필요한 범위만 확정한다. 정식 마을 아트, 상점 UI, 퀘스트 시스템, 성장 시스템, 저장 시스템은 이번 작업의 핵심 범위에서 제외한다.

이번 단계의 목표는 다음 조건을 만족하는 것이다.

- 플레이어가 마을에서 정상적으로 시작한다.
- 마을 내 이동 가능 영역이 명확하다.
- 카메라가 플레이어를 안정적으로 따라간다.
- 마을에서 던전 또는 스테이지로 이동할 수 있다.
- 던전/전투 종료 후 마을의 지정 위치로 돌아올 수 있다.

### 3. 씬 보강

기존 마을씬을 기준으로 레이아웃, 충돌, 카메라, 시작 위치를 조정한다. 외부 에셋 원본은 직접 수정하지 않고, 프로젝트 소유 씬과 필요한 경우 복사된 프리팹을 기준으로 작업한다.

우선순위는 다음 순서로 둔다.

```text
Spawn Point
-> Return Spawn Point
-> 이동 가능 영역
-> 맵 경계 Collider
-> Camera Follow/Boundary
-> Portal/Trigger
```

### 4. 귀환 흐름 연동

전투 또는 던전 종료 후 마을씬으로 돌아올 때, 플레이어가 일반 시작 위치가 아니라 귀환 지점에 배치될 수 있도록 분리한다.

권장 오브젝트 이름:

- `TownSpawnPoint`: 마을 최초 진입 또는 기본 시작 위치
- `TownReturnSpawnPoint`: 던전/전투 종료 후 귀환 위치
- `Portal_ToDungeon`: 마을에서 던전 또는 스테이지로 이동하는 트리거

씬 이동 로직이 이미 존재하면 기존 구조를 우선 사용한다. 새 스크립트가 필요할 경우에는 프로젝트 네임스페이스와 폴더 구조를 따른다.

### 5. UI, NPC 자리, 사운드 정리

마을에서는 전투 중에만 필요한 UI가 계속 노출되지 않도록 정리한다. NPC 기능은 아직 구현하지 않더라도 추후 상점, 회복, 퀘스트 연결을 위해 위치와 상호작용 범위만 확보한다.

사운드는 최종 리소스가 없으면 임시 BGM 또는 환경음 연결 여부만 확인하고, 리소스 확정은 별도 작업으로 분리한다.

### 6. 통합 테스트

최소 테스트 흐름은 다음과 같다.

```text
마을씬 직접 실행
-> 플레이어 시작 위치 확인
-> 마을 이동 및 충돌 확인
-> 카메라 추적/경계 확인
-> 포탈로 던전 또는 스테이지 이동
-> 던전/전투 종료 조건 실행
-> 마을씬 복귀
-> 귀환 위치 배치 확인
-> UI 노출 상태 확인
```

## 완료 기준

- 기존 마을씬 기준 후속 작업 범위가 문서화되어 있다.
- 마을 최초 진입 위치와 귀환 위치가 구분되어 있다.
- 플레이어가 마을에서 비정상 위치로 벗어나지 않는다.
- 카메라가 마을 플레이 영역을 기준으로 정상 동작한다.
- 마을에서 던전 또는 스테이지로 이동할 수 있다.
- 던전/전투 종료 후 마을로 돌아오는 흐름이 연결되어 있다.
- 마을에서 불필요한 전투 UI가 노출되지 않는다.
- 통합 테스트 체크리스트 기준으로 주요 흐름을 확인했다.

## 주의 사항

- 기존 Unity 씬, 프리팹, 에셋 파일은 Unity Editor를 통해 수정한다.
- 외부 에셋 원본을 직접 수정하지 않는다.
- `.unity`, `.prefab`, `.asset`, `.meta` 파일이 변경될 경우 변경 파일과 위험 범위를 별도로 설명한다.
- 현재 문서는 작업 계획 문서이며, 실제 Unity serialized 파일은 수정하지 않았다.
