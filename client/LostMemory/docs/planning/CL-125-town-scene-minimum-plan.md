# CL-125 마을씬 최소 기획 확정

## 작업 개요

- 에픽: Epic R. 마을/귀환 흐름
- 영역: Planning
- 작업코드: CL-125
- 작업명: 마을씬 최소 기획 확정
- 담당: 클라2
- 우선순위: P1
- 산출물: 마을씬 요구사항 메모

## 목적

정식 마을 맵이 제작되기 전까지 사용할 임시 허브 씬의 최소 요구사항을 확정한다.

초기 마을씬은 플레이어가 던전 또는 스테이지 씬으로 이동할 수 있는 포탈만 배치하는 수준으로 구성한다. 이후 마지막 스테이지 보스 클리어 후 생성되는 귀환 포탈을 통해 다시 마을로 돌아오는 흐름과 연결할 수 있어야 한다.

## 초기 범위

이번 단계의 마을씬은 최종 마을 콘텐츠가 아니라 씬 이동 흐름 검증용 임시 공간으로 본다.

- 플레이어 시작 위치를 제공한다.
- 던전 이동 포탈을 배치한다.
- 플레이어가 포탈까지 이동할 수 있는 최소 바닥 영역을 둔다.
- 카메라가 플레이어를 정상적으로 보여줄 수 있어야 한다.
- 던전 이동 후 다시 마을 귀환 흐름을 붙일 수 있는 구조로 둔다.

## 최소 구성 요소

| 항목 | 이름 예시 | 설명 |
|---|---|---|
| 마을 씬 | `Town` | 임시 허브 씬 |
| 플레이어 시작점 | `TownSpawnPoint` | 마을 진입 시 플레이어가 생성되거나 배치될 위치 |
| 던전 이동 포탈 | `Portal_ToDungeon` | 접촉 또는 상호작용 시 던전/스테이지 씬으로 이동 |
| 이동 가능 바닥 | `TownFloor_Temp` | 임시 바닥 또는 테스트용 타일 |
| 카메라 | 기존 카메라 구성 재사용 | 플레이어 추적 또는 고정 카메라 중 현재 구조에 맞는 방식 사용 |

## 포탈 이동 흐름

초기 구현 흐름:

```text
Town
-> Dungeon 또는 Stage01
```

최종 연결 목표:

```text
Town
-> Dungeon 또는 Stage
-> 마지막 스테이지 보스 클리어
-> 귀환 포탈 생성
-> Town
```

초기에는 던전 이동 대상 씬을 하나로 고정해도 된다. 다만 포탈 스크립트가 씬 이름을 직접 강하게 들고 있기보다는, 가능하면 기존 씬 이동 관리자 또는 별도 씬 이동 API를 통해 이동하도록 설계한다.

## 제외 범위

이번 작업에서는 아래 항목을 만들지 않는다.

- 정식 마을 맵 아트
- NPC 배치
- 상점 UI
- 강화 또는 성장 시스템
- 대화 시스템
- 퀘스트 시스템
- 저장 지점
- 최종 BGM/SFX
- 마을 전용 연출

## 완료 기준

- 마을씬의 역할과 초기 범위가 문서로 정리되어 있다.
- 초기 마을씬에는 던전 이동 포탈만 배치해도 된다는 기준이 확정되어 있다.
- 플레이어 시작 위치, 던전 이동 포탈, 최소 이동 가능 영역이 필수 구성 요소로 정의되어 있다.
- 이후 보스 클리어 후 귀환 포탈로 마을에 돌아오는 흐름과 연결 가능한 구조가 명시되어 있다.
