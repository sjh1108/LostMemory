# CL-053 보스 체력 단계별 패턴 전환 처리 구현 완료 문서

## 문서 목적

`CL-053 보스 체력 단계별 패턴 전환 처리 구현`의 현재 구현 현황, 적용 방식, 검증 결과, 남은 확인 사항을 정리한다.

CL-053은 CL-051, CL-052에서 구현된 Bertha 보스 전투 루프를 기반으로, 체력 비율에 따라 보스의 전투 페이즈와 패턴 선택 규칙이 달라지도록 만드는 작업이다.

## 구현 내용

### 1. BerthaBossPhase

Bertha 보스의 체력 페이즈를 명시하는 enum을 추가했다.

```csharp
public enum BerthaBossPhase
{
    Phase1 = 1,
    Phase2 = 2,
    Phase3 = 3
}
```

페이즈는 숫자가 커질수록 전투 후반부를 의미한다.

### 2. BerthaBossPhaseController

`Health`를 기준으로 현재 체력 비율을 계산하고, 체력 구간에 따라 현재 페이즈를 결정한다.

| 페이즈 | 조건 | 의미 |
|---|---|---|
| Phase1 | 70% 초과 | 기본 전투 구간 |
| Phase2 | 70% 이하, 30% 초과 | 특수 패턴 해금 구간 |
| Phase3 | 30% 이하 | 후반 강화 구간 |

주요 동작:

- `Health.OnHit`을 구독해 피격 시 페이즈를 재평가한다.
- `Health.OnDeath`에서 사망 이후 추가 평가를 중단한다.
- 페이즈는 낮은 단계로 되돌아가지 않는다.
- 페이즈가 올라갈 때 `PhaseChanged(previous, current)` 이벤트를 발행한다.
- `phase2ThresholdNormalized`, `phase3ThresholdNormalized`는 Inspector에서 조정 가능하다.

### 3. BerthaCombatPatternSelector 페이즈 확장

기존 selector는 거리, 쿨다운, 가중치, 체력 임계치 기준으로 패턴을 선택했다. CL-053에서는 여기에 `PhasePatternSettings`를 추가해 현재 페이즈별로 패턴 선택 규칙을 다르게 적용한다.

현재 기본 페이즈 설정:

| 항목 | Phase1 | Phase2 | Phase3 |
|---|---:|---:|---:|
| LightAttack1Weight | 3 | 2 | 1 |
| LightAttack2Weight | 3 | 3 | 2 |
| HeavyAttackWeight | 2 | 3 | 3 |
| NormalDashWeight | 1 | 2 | 2 |
| AllowDashAttack | false | true | true |
| AllowFullCombo | false | true | true |
| NormalDashCooldown | 10s | 8s | 6s |
| DashCooldown | 15s | 12s | 9s |
| FullComboCooldown | 15s | 12s | 9s |

의도:

- Phase1은 기본 패턴 중심으로 시작한다.
- Phase2부터 `DashAttack`, `FullCombo`를 허용한다.
- Phase3에서는 강한 패턴 쿨다운을 더 줄여 후반 압박을 높인다.
- 기존 단일 설정값은 fallback으로 남겨, PhaseController가 없더라도 기존 방식으로 동작할 수 있게 했다.

### 4. BerthaLightAttack1Bootstrap 연결

`BerthaLightAttack1Bootstrap`에서 Bertha 전투 구성을 재생성할 때 `BerthaBossPhaseController`를 자동으로 붙이고 설정한다.

연결 기준:

```text
Phase2 threshold = stunThresholdNormalized  = 0.7
Phase3 threshold = tiredThresholdNormalized = 0.3
```

즉, 기존 임계치 연출과 페이즈 전환 기준이 서로 어긋나지 않게 맞췄다.

```text
70% 이하:
  - BerthaBossPhaseController: Phase2 진입
  - BerthaHealthThresholdReactionController: Stun 연출 큐잉

30% 이하:
  - BerthaBossPhaseController: Phase3 진입
  - BerthaHealthThresholdReactionController: Tired 연출 큐잉
```

## 런타임 흐름

권장 동작 흐름은 다음과 같다.

```text
보스 피격
  -> Health.OnHit
  -> BerthaBossPhaseController가 체력 비율 평가
  -> 필요 시 Phase1 -> Phase2 또는 Phase2 -> Phase3 전환
  -> BerthaHealthThresholdReactionController가 임계치 연출 처리
  -> 보스가 전투 상태로 복귀
  -> BerthaCombatPatternSelector가 현재 Phase 설정으로 다음 패턴 선택
```

임계치 연출 중에는 기존 구조처럼 AI와 이동이 잠시 멈춘다. 연출이 끝난 뒤 새 페이즈의 패턴 규칙이 적용된다.

## Unity 적용 상태

코드상으로는 `BerthaLightAttack1Bootstrap`이 `BerthaBossPhaseController`를 자동으로 생성하고 selector에 연결한다.

Unity에서 프리팹에 명시적으로 저장하려면 다음 작업이 필요하다.

```text
BerthaRoot 또는 BerthaRoot2 선택
  -> BerthaLightAttack1Bootstrap
  -> Rebuild Bertha Combat Pattern 실행
  -> Bertha Boss Phase Controller 생성 확인
  -> Prefab Apply 또는 Scene Save
```

사용자 수동 확인 기준으로 Unity 적용 확인은 완료된 것으로 기록한다. 다만 최종 커밋 전에는 `git status`에서 프리팹 또는 씬 변경이 의도대로 포함됐는지 확인해야 한다.

## 남은 확인 사항

CL-053 자체 구현은 완료로 보되, 다음 항목은 후속 정리 또는 커밋 전 확인 대상으로 남긴다.

## 결론

CL-053은 Bertha 보스의 체력 기반 전투 페이즈 전환 구조를 완성한 작업이다.

기존 `Stun 70%`, `Tired 30%` 임계치 연출을 유지하면서, 동일한 기준으로 Phase2, Phase3 전투 규칙을 적용하도록 정리했다. 패턴 선택기는 현재 페이즈에 따라 특수 패턴 허용 여부, 가중치, 쿨다운을 다르게 사용한다.

현재 상태에서는 CL-053 구현을 완료로 보고, 다음 단계는 CL-054 보스 처치 후 클리어/출구/보상 흐름으로 넘어가면 된다.
