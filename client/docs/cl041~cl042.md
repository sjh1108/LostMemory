## CL-041 구현 내용

### 1. 원거리 AI 상태 흐름 구성

`SkeletonArcher_CL041.prefab` 기준으로 아래 상태 흐름이 구성되어 있다.

- `Idle`
- `Approach`
- `Retreat`
- `AimReady`
- `Attack`
- `Recover`
- `Reposition`
- `Reset`

기본 동작은 다음과 같다.

1. 플레이어를 감지하면 `Approach`로 진입
2. 너무 가까우면 `Retreat`
3. 적정 거리면 `AimReady`
4. 조준 후 `Attack`
5. 발사 후 `Recover`
6. 후딜 후 `Reposition`에서 거리 재평가

### 2. 거리 유지 규칙

현재 프리팹 기준 주요 거리 값은 다음과 같다.

- 감지 반경: `7.5`
- 너무 가까움: `3`
- 공격 준비 가능 거리: `5.5`
- 다시 접근해야 하는 거리: `5.8`
- 추적 포기 거리: `9`
- 후퇴 완료 거리: `3.4`

즉, Skeleton Archer는 플레이어에게 붙지 않고
일정 거리 밴드를 유지하면서 전투를 수행하는 구조다.

### 3. 조준/공격/후딜 시간 분리

상태 전이는 시간 기반 decision으로 분리되어 있다.

- `AimFinished = 2초`
- `AttackFinished = 0.1초`
- `RecoverFinished = 2초`

현재 전투 사이클은 아래처럼 반복된다.

1. `AimReady`에서 2초 조준
2. `Attack`에서 1발 발사
3. `Recover`에서 2초 후딜
4. `Reposition`에서 거리 재평가

이 구조 덕분에 조준 시작 후 공격이 쉽게 취소되지 않고,
원거리 적다운 템포가 유지된다.

## CL-042 구현 내용

### 1. 활 무기 프리팹 추가

`Assets/_Project/Prefabs/Weapons/ArcherBow.prefab`

`ArcherBow`는 보이는 활 오브젝트가 아니라
`ProjectileWeapon` 기반의 로직 무기 프리팹이다.

현재 주요 설정:

- `TriggerMode = SemiAuto`
- `TimeBetweenUses = 4`
- `SingleUseAnimationParameter = Attack`
- `ProjectileSpawnOffset = (1.8, -0.1, 0)`
- `GameObjectToPool = ArcherArrow`

권총 데모 프리팹을 기반으로 복제해서 만들었고,
총구 불꽃, 탄피 같은 총기 연출은 비활성화된 상태다.

### 2. 화살 투사체 프리팹 추가

`Assets/_Project/Prefabs/Weapons/Projectiles/ArcherArrow.prefab`

현재 화살 프리팹은 아래 기준으로 정리되어 있다.

- `LifeTime = 4`
- `Speed = 55`
- `TargetLayerMask = Player`
- `Damage = 10`
- `GravityScale = 0`
- `BoxCollider2D.size = (0.4, 0.15)`
- 가시성 보정을 위한 스케일 확대 적용

비주얼은
`Assets/_Project/Art/Enemies/Skeleton Archer/Arrow(projectile)/`
하위 리소스를 사용한다.

### 3. Skeleton Archer와 무기 연결

`SkeletonArcher_CL041.prefab`에는 다음 연결이 반영되어 있다.

- `CharacterHandleWeapon.InitialWeapon = ArcherBow`
- `CharacterHandleWeapon.ProjectileSpawn = ProjectileSpawn`
- `WeaponAttachment` / `ProjectileSpawn` 자식 구조 유지

즉, Skeleton Archer는 스폰 시 `ArcherBow`를 장착하고,
`ProjectileSpawn` 기준으로 `ArcherArrow`를 발사한다.

### 4. 실제 발사 상태 구성

AI 액션 구성은 아래와 같다.

`AimReady`
- `AIActionFaceTowardsTarget2D`
- `AIActionAimWeaponAtTarget2D`

`Attack`
- `AIActionFaceTowardsTarget2D`
- `AIActionAimWeaponAtTarget2D`
- `AIActionShoot2D`

이 구조 덕분에
조준 상태와 실제 발사 상태가 분리되어 있고,
발사 타이밍을 상태 전이로 제어할 수 있다.

## 애니메이션 반영 내용

`Assets/_Project/Art/Animations/Enemies/SkeletonArcher/SkeletonArcher.controller`

현재 사용 중인 주요 파라미터:

- `Walking`
- `Attack`
- `Death`
- `Damage`

`Attack` 파라미터는 `bool` 기반으로 연결되어 있으며,
무기 사용 시 공격 모션이 함께 보이도록 정리되어 있다.

즉, Skeleton Archer는 화살만 발사하는 것이 아니라
공격 애니메이션과 발사 연출이 함께 동작한다.

## 추가 반영: 조준 예고선

최근 추가 작업으로 조준 상태를 시각적으로 보여주는 텔레그래프가 들어갔다.

추가 파일:

- `Assets/_Project/Scripts/Runtime/Combat/Telegraph/AIBrainRangedTelegraphDriver.cs`

프리팹 반영:

- `SkeletonArcher_CL041.prefab`에 `AttackTelegraph2DView` 추가
- `AIBrainRangedTelegraphDriver` 추가
- `telegraphStateName = AimReady`

현재 동작:

1. `AimReady` 상태에 들어가면 예고선 표시
2. 타겟 방향으로 조준 박스 갱신
3. `Attack` 또는 상태 이탈 시 예고선 제거

현재 주요 값:

- `fallbackLength = 5.5`
- `maximumLength = 6.5`
- `width = 0.35`
- `startOffset = 0.1`

## 검증 메모

파일 반영 기준으로는 CL-041 / CL-042 구현이 완료된 상태로 볼 수 있다.

다만 이후 플레이 테스트 기준으로 아래 값은 추가 조정 가능하다.

- 화살 속도
- 화살 수명
- 공격 주기
- 조준 시간
- 예고선 길이/두께
- 거리 밴드

또한 최근 작업에는 Unity 직렬화 `.prefab`, `.controller`를 직접 수정한 변경이 포함되어 있으므로,
Unity Editor에서 프리팹과 Animator가 경고 없이 열리는지 확인하는 것이 안전하다.
