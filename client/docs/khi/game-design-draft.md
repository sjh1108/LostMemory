# 게임 상세 기획 초안

> 본 상세 기획서는 차후 시스템별 문서로 분리될 예정이다.  
> 이 문서는 현재까지 정리된 내용을 한곳에 모아 용어를 통일하고, 게임 구조를 더 명확히 이해하기 위한 초안이다.

## 1. 문서 목적

- 팀 내 용어 선정과 표현을 통일한다.
- 로비, 스테이지, 무기, 유물, 재능, 기억 시스템의 큰 흐름을 정리한다.
- 이후 상세 기획서로 분리할 시스템 단위를 정의한다.
- 구현 우선순위와 미정 사항을 식별한다.

## 2. 핵심 구조 요약

게임은 로비에서 메타 성장과 무기/재능 선택을 진행한 뒤, 스테이지에 진입해 방을 돌파하고 보스를 처치하는 2D 탑다운 액션 로그라이크 구조를 가진다.

```text
로비
  ├─ 기억 시스템
  ├─ 재능 선택
  └─ 무기 선택

스테이지 진행
  ├─ 큰방 반복
  │   └─ 작은방 5개
  ├─ 상점
  └─ 보스방

런 종료 / 보스 격파
  └─ 기억의 파편 획득
```

## 3. 용어 정의

| 용어 | 정의 | 비고 |
|---|---|---|
| 로비 | 런 시작 전 준비 공간 | 기억 시스템, 재능, 무기 선택 포함 |
| 스테이지 | 하나의 큰 진행 단위 | 큰방, 상점, 보스방으로 구성 |
| 큰방 | 여러 작은방으로 구성된 진행 구간 | 기본 4개, 개수 조절 가능 |
| 작은방 | 실제 전투가 발생하는 단위 방 | 기본적으로 큰방 1개당 작은방 5개 |
| 탈출구 | 다음 방으로 이동하는 출구 | 방 클리어 전에는 이용 불가 |
| 상점 | 아이템/포션을 돈으로 구매하는 방 | 보스 전 자원 관리 지점 |
| 보스방 | 보스가 등장하는 방 | 보스 처치 시 다음 단계 진행 |
| 유물 | 런 동안만 적용되는 보상 아이템 | 중복 획득 불가 |
| 비유물 보상 | 유물이 아닌 보상 | 회복약, 랜덤 박스 등 |
| 태그 | 유물의 세트 효과 분류 | 현재 맹공, 수호, 질주 |
| 재능 | 런 시작 전 투자하는 능력치 | 치명타 확률, 공속 등 |
| 기억 | 메타 성장의 큰 퍼즐 | 총 4개 목표 |
| 기억의 조각 | 기억을 구성하는 퍼즐 조각 | 해금 시 특수 효과 제공 |
| 기억의 파편 | 기억의 조각 해금에 쓰는 메타 재화 | 보스 격파 보상 |
| 사파이어 | 기억의 조각 선택/각인에 사용하는 재화 후보 | 명칭 확정 필요 |

## 5. 스테이지 진행

### 5.1 기본 구성

하나의 스테이지는 다음 구조를 가진다.

| 구성 요소 | 기본 개수 | 조절 가능 여부 | 설명 |
|---|---:|---|---|
| 큰방 | 4개 | 가능 | 스테이지의 주요 전투 구간 |
| 상점 | 1개 | 고정 | 아이템 3종과 포션을 구매 가능 |
| 보스방 | 1개 | 고정 | 보스 처치 후 다음 단계 진행 |

### 5.2 큰방 구성

큰방 하나는 작은방 5개로 구성된다.

```text
큰방
  ├─ 작은방 1
  ├─ 작은방 2
  ├─ 작은방 3
  ├─ 작은방 4
  └─ 작은방 5
```

### 5.3 작은방 규칙

- 작은방에 진입하면 전투가 시작된다.
- 방 내부의 적을 모두 처치하기 전까지 탈출할 수 없다.
- 모든 적을 처치하면 탈출구가 활성화된다.
- 탈출구에 도달하면 다음 방으로 이동한다.

### 5.4 상점

상점은 전투 중 획득한 돈을 소비해 아이템과 포션을 구매하는 방이다.

| 판매 항목 | 개수 | 설명 |
|---|---:|---|
| 아이템 | 3종 | 빌드 강화 선택지 |
| 포션 | 1종 | 체력 회복 수단 |

상점의 의도는 체력 관리와 보상 선택 사이의 긴장을 만드는 것이다.

- 체력을 많이 잃은 플레이어는 포션 구매를 고려한다.
- 체력을 아낀 플레이어는 포션 대신 아이템을 구매할 수 있다.
- 이를 통해 전투 숙련도가 빌드 성장 선택지로 연결된다.

### 5.5 보스방

- 보스가 존재하는 방이다.
- 보스를 처치하면 다음 단계로 진행한다.
- 보스 격파는 기억의 파편 지급 기준 보상과 연결된다.

## 6. 무기 시스템

### 6.1 무기 종류

현재 기획된 무기 종류는 다음과 같다.

| 무기 | 비고 |
|---|---|
| 검 | 근접 무기 |
| 망치 | 근접 무기 |
| 칼 | 검과 구분 기준 필요 |
| 활 | 원거리 무기 |

> `검`과 `칼`은 용어와 역할이 겹칠 수 있으므로, 추후 무기 상세 기획에서 명확히 구분해야 한다.

### 6.2 무기 강화 방향

무기 강화는 런 중 즉시 선택 강화가 아니라, 외부 성장 시스템을 통해 강화 단계를 해금하는 방식이다.

```text
마을 / 외부 상점
  └─ 모루 시스템
      └─ 무기 강화 단계 해금
          └─ 런 시작 전 강화 단계 선택
```

### 6.3 강화 규칙 초안

- 강화 단계는 외부 시스템에서 해금한다.
- 플레이어는 런 시작 전 사용할 강화 단계를 선택한다.
- 강화 선택은 해당 런의 전투 스타일에 영향을 준다.
- 상세 수치와 단계별 효과는 추후 무기 상세 기획서에서 정의한다.

## 9. 기억 시스템

기억 시스템은 하나의 메인 퍼즐이자 메타 해금 목표다.

### 9.1 기본 개념

| 용어 | 설명 |
|---|---|
| 기억 | 하나의 큰 퍼즐, 메인 해금 목표 |
| 기억의 조각 | 기억을 구성하는 개별 퍼즐 조각, 해금 시 특수 효과 제공 |
| 기억의 파편 | 플레이 보상으로 획득하는 메타 재화, 기억의 조각 해금에 사용 |

### 9.2 기억의 파편 획득

- 기억의 파편은 보스 격파 기준 보상으로 획득한다.
- 한 판이 끝날 때마다 지급되는 형식이다.
- 획득한 기억의 파편은 기억의 조각 해금에 사용한다.

### 9.3 기억 해금 흐름

```text
보스 격파
  └─ 기억의 파편 획득
      └─ 기억의 파편 일정량 소모
          └─ 서브 기억 / 기억의 조각 획득
              └─ 필요한 조각을 모두 모으면 메인 기억 완성
                  ├─ 단편 기억 스토리 해금
                  └─ 무기 해금
```

### 9.4 퍼즐 크기

메인 기억 하나를 완성하기 위한 서브 기억 개수는 순차적으로 증가한다.

| 단계 | 퍼즐 크기 | 조각 수 |
|---|---|---:|
| 1단계 | 1 x 1 | 1개 |
| 2단계 | 2 x 2 | 4개 |
| 3단계 | 4 x 4 | 16개 |

### 9.5 전체 목표

- 총 4개의 메인 기억을 모아야 한다.
- 메인 기억마다 단편 기억 스토리가 존재한다.
- 메인 기억마다 무기 해금과 연결된다.

### 9.6 기억의 조각 효과 예시

기억의 조각은 선택 시 사파이어 또는 관련 재화를 사용하며, 하나의 특수 효과를 가진다.

| 효과 예시 | 설명 |
|---|---|
| 재능 포인트 부여 | 시작 전 투자 가능한 재능 포인트 증가 |
| 시작 시 포션 지급 | 런 시작 아이템 제공 |
| 대시 추가 | 대시 관련 능력 추가 |
| 대시 쿨타임 감소 | 이동/회피 성능 강화 |
| 대시 시 무적시간 증가 | 생존력 강화 |
| 최대 체력 증가 | 기본 생존력 증가 |
| 레벨업 시 회복 체력 증가 | 성장 보상 강화 |

### 9.7 기억 완성 연출

- 기억 내 모든 조각을 플레이어가 맞추면 기억이 완성된다.
- 퍼즐 완성 시 완성된 기억 이미지를 3초간 보여준다.
- 이후 다음 화면 또는 보상 화면으로 넘어간다.

이미지 자리:

```text
[기억 퍼즐 UI / 기억 완성 이미지]
```

## 10. ComfyUI 활용 계획

ComfyUI는 이미지 AI 생성 플로우를 직접 제작하는 프로그램이다.

### 10.1 현재 상태

- 로컬 서버로 실행 중이다.
- 개인 PC의 GPU를 사용해 이미지를 생성한다.
- 무료로 로컬 실행이 가능하다.
- 이미지 생성 플로우를 직접 제작할 수 있다.

### 10.2 장단점

| 구분 | 내용 |
|---|---|
| 장점 | 로컬 실행 가능, 무료 사용 가능, 이미지 생성 플로우 직접 제작 가능 |
| 단점 | 팀 내 공유가 어렵고, 플로우 제작 난이도가 높음 |

### 10.3 1차 목표

현재 로컬에서만 접근 가능한 ComfyUI 페이지를 내부 서버로 띄워 팀 내 공유가 가능하도록 한다.

```text
개인 로컬 ComfyUI
  └─ 내부 서버 공유
      └─ 팀원 접근 가능
```

### 10.4 2차 목표

오픈소스 기반으로 다음 기능을 추가하는 방향을 검토한다.

- 동시 작업
- 작업 공유
- 이미지 공유
- 작업 내용 공유
- AI 개선 작업

이미지 자리:

```text
[ComfyUI 플로우 화면 이미지]
```

## 12. 현재 미정 사항

| 항목 | 미정 내용 |
|---|---|
| 검 / 칼 구분 | 두 무기의 역할과 차별점 필요 |
| 사파이어 | 기억의 조각 해금 재화인지, 별도 각인 포인트인지 확정 필요 |
| 서브 기억 / 기억의 조각 | 두 용어를 하나로 합칠지 구분할지 결정 필요 |
| 상점 상품 | 아이템 3종의 선정 방식, 가격, 등급 규칙 필요 |
| 방 배치 | 큰방 4개와 작은방 5개가 고정인지, 랜덤 배치인지 결정 필요 |
| 보상 지급 시점 | 작은방, 큰방, 보스방 중 어느 시점에 유물 보상을 줄지 결정 필요 |
| 유물 중복 예외 | 중복 불가 원칙에 대한 예외 여부 결정 필요 |
| 패링 | 반격의 표식이 패링을 전제로 하므로 패링 시스템 존재 여부 확인 필요 |
| 마나 | 재능에 마나 회복이 있으므로 마나/스킬 시스템 정의 필요 |
| 레벨업 | 기억 조각 효과에 레벨업 회복이 있으므로 런 중 레벨업 시스템 확인 필요 |
