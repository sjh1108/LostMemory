## 4. 당면 과제 (CL-011 ~ CL-015) 상세 설계

### [CL-011] 대시 구현 및 무적 시간 기본안 적용
- **개요**: 이동 중 대시 버튼 입력 시, 바라보는 방향 혹은 입력 방향으로 짧게 돌진하며 일시적인 무적 상태를 부여.
- **구현 방식**:
  1. `Input System`: Dash 액션 바인딩 검증.
  2. `CharacterDash` (TDE 확장): TopDown Engine의 기존 대시 컴포넌트를 베이스로 하되, 이동 거리와 속도를 게임 템포에 맞게 조정.
  3. **무적 시간 (I-Frame)**: 대시가 시작되는 프레임부터 특정 시간(예: 0.2~0.3초) 동안 TDE의 `Health` 컴포넌트의 Damage 무시(Invulnerable) 로직 활성화.
  4. **쿨타임**: 대시 남발을 막기 위한 쿨타임(예: 1.5초) 적용.

### [CL-012] 타이밍 패링 구현
- **개요**: 적의 공격이 닿기 직전 방어(패링) 키를 입력해 데미지를 무효화하고 적에게 빈틈을 생성.
- **구현 방식**:
  1. `Input System`: Parry 액션 바인딩 검증.
  2. `ParryComponent` (신규): 패링 입력 시 일정 시간(Parry Window, 예: 0.15초) 동안 패링 활성 상태로 전환.
  3. **판정 로직**: 플레이어 `Health`가 데미지를 받기 직전의 이벤트를 가로채어(TDE Damage Resistance 또는 이벤트 훅 사용), 패링 활성 상태라면 데미지를 무효화.
  4. **후속 처리**: 패링 성공 시 글로벌 이벤트(`ParrySuccessEvent`) 발생시켜 히트스톱, 적 경직 등을 연계.

### [CL-013 ~ CL-015] 피격, 다운, 부활 및 상태머신 정리
- **피격 (CL-013)**: 데미지 발생 시 애니메이터 `Hit` 트리거 및 잠깐의 제어 불가 상태(경직) 부여.
- **다운/부활 (CL-014)**: 체력이 0이 되었을 때 사망(Destroy) 처리 대신 `Down` 상태로 진입(이동/공격 불가). 멀티플레이를 고려해 다른 플레이어가 근처에서 상호작용 시 일정 체력으로 부활하는 로직의 뼈대 작성.
- **상태머신 (CL-015)**: TDE의 `CharacterStates.CharacterConditions` 와 `CharacterStates.MovementStates`를 재점검하여 Idle/Move/Attack/Dash/Parry/Hurt/Down 이 충돌 없이 매끄럽게 전이되는지 구조화.
