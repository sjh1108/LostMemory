# 무기 시스템 디자인

> 2026-05-14 기준 결정사항 정리. 이후 무기/스킬/유물 작업의 기준점.

## 핵심 골격

```
무기 슬롯: 2개 (자유 조합, 즉시 전환)
공통 자원: 마나 (UI 1개, 모든 무기 공유)
평타     → 마나 충전 + 약한 딜
스킬 1   → 마나 50% / 짧은 쿨 / 주력기
스킬 2   → 마나 100% / 긴 쿨 / 강력한 한 방
마나 보조: 적 처치 보너스, 시간당 자연 회복
```

## 무기 4종

| 무기 | 정체성 | 깊이 장치 |
|---|---|---|
| 검 | 평타 | 콤보 피니셔 (3타째 강타) |
| 활 | 평타 | 차지샷 |
| 봉 | 평타 + 1스킬 | 스킬 입문용 |
| 스태프 | 스킬 2개 | 쿨다운/마나 운영 |

각 무기 강화 3 path: **스피드 / 밸런스 / 파워**

- 검: 단검(스피드) / 방패검(밸런스) / 대검(파워)
- 활: 노(스피드) / 총(밸런스) / 화염방사·유탄(파워) — 추후 재블린/대포로 2차 강화
- 봉: 여의봉(스피드) / 창(밸런스) / 망치(파워)
- 스태프: 트페식 공속(스피드) / 순수 마법사(밸런스) / 비숍(파워)

## 스태프 스킬 설계

| 강화 | 스킬1 (주력, 마나 50%) | 스킬2 (한방, 마나 100%) |
|---|---|---|
| 트페 (스피드) | 다단 마법탄 (3발 부채꼴) | 단거리 블링크 |
| 마법사 (밸런스) | 파이어볼 (관통) | 메테오 (광역 폭발) |
| 비숍 (파워) | 신성 광선 (차지 단발) | 배리어 / 힐존 |

**base 모듈 2개** (단발 투사체 + 광역 효과) + 파라미터 변주로 구현.

## 빌드 = 무기 조합

무기 2개 슬롯 자유 조합. 조합 자체가 플레이스타일을 정의:

- **검 + 검** → 평타 양손잡이. 마나 거의 안 씀.
- **스태프 + 스태프** → 순수 마법사. 충전 느림, 적 처치/자연회복 의존.
- **검 + 스태프** → 균형형. 검 충전 → 스태프 폭딜 사이클. 가장 인기 빌드 예상.
- **활 + 봉** 등 → 무기 4 × 4 = 16 조합 × 강화 path까지 = 수십 가지 빌드.

## 유물 시스템

- **이원화**: 패시브 / 액티브
- 액티브 쪽엔 시각적 변화 동반 (player engagement ↑)
- 마나 회복·쿨감·평타 강화 등은 **공통 마나 시스템 위에서** 디자인 (무기 종속 X)

## 속성 (MVP 이후)

- 4원소 + 무속성: 불 / 물 / 전기 / 바람 / 무속성
- 흙 제외 (시각·메카닉 양쪽 약함)
- **속성은 무기·강화 다 끝낸 후 한 번에 입힘** — 따로따로 작업하면 시스템 지저분

## 작업 순서 (제안)

1. 활 + 스태프 추가 (무속성, 단일 단계) — 무기 슬롯 시스템 확장
2. 단검/대검 (검 강화 path 1개씩) — 강화 시스템 검증
3. 봉
4. 속성 4개 동시 입히기
5. 유물 이원화

## 미결정 / 추후 결정

- 무기 전환 키 (Q / 마우스휠 / 숫자키)
- 무기 동시 표시 vs 등에 메고 활성 하나만 (추천: 후자)
- 마나 풀 크기·충전 속도 구체 수치
- 강화 단계 수 (3단계 추천, *5는 안 함)
- 검 패링은 유지/제거? (스킬 추가하면서 빼는 안 있었음)
- 스태프+스태프 빌드 약점 보정 (지팡이 동조 보너스 등 — 밸런싱 단계)

## 디자인 원칙

- **읽기 쉬운 정체성** — 평타 무기 vs 스킬 무기 이분법은 플레이어가 한 번에 이해.
- **공통 문법** — 모든 무기의 "강한 동작"은 "마나 풀충전 후 한 방"으로 묶임.
- **조합이 빌드** — 무기 슬롯 2개 + 자유 조합으로 빌드 다양성 자동 확보.
- **base 모듈 재사용** — 강화 path는 파라미터 변주로. 무기마다 처음부터 만들지 않음.
