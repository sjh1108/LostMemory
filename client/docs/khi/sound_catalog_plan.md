# Sound Catalog 작성 계획

## Context
프로젝트(`LostMemory`)에는 자체 사운드 파일이 없고, 모든 사운드는 TopDownEngine/MMInterface/MMFeedbacks 등 외부 패키지에 분산되어 있다(총 ~191개). 매번 프리팹 작업할 때마다 검색하는 비용을 줄이기 위해, 사용 가능한 사운드를 한 문서에 정리해두고 "특정 상황에 어울리는 사운드가 있는지" 빠르게 매칭할 수 있도록 한다.

목표: `docs/khi/sound.md` 카탈로그 1장 작성. 카테고리별 그룹화 + 각 항목에 (분위기/스타일, 추천 사용처, 에셋 경로) 메타데이터 표시.

## 결과물

### 파일
- **경로**: `client/docs/khi/sound.md` (단일 파일)
- **포맷**: 카테고리별 H2 섹션 → 항목별 표(table)

### 표 컬럼
| 파일명 | 분위기/스타일 | 추천 사용처 | 에셋 경로 |

- **분위기/스타일**: 파일명에서 추정 (예: "픽셀톤 카툰, 짧음", "3D 사실적, 묵직")
- **추천 사용처**: 게임 내 어울리는 상황 (예: "검사 캐릭터 공격", "UI 클릭", "보스 등장")
- **에셋 경로**: `Assets/...` 로 시작하는 풀 경로 — Unity Inspector에서 바로 참조 가능

### 카테고리 (H2)
이미 조사된 분류를 따른다:
1. 무기/공격 (근접/사격/재장전)
2. 발소리/이동 (걷기/달리기/점프/대시)
3. 피격/사망
4. 아이템/획득
5. 패링/방어 — 해당 후보 있는지 재확인
6. UI/인터페이스 (MMInterface)
7. 게임플레이 피드백 (MMFeedbacks)
8. 인벤토리 (InventoryEngine)
9. 환경/BGM/앰비언트
10. 기타 데모 (DungeonArchitect, Unity Timeline)

### 머리말
- "이 파일은 어디서 왔는지 / 어떻게 갱신하는지" 한 문단
- "프리팹 매칭 사용법" 한 문단 ("어떤 상황 → 카테고리 → 표 검색" 안내)

## 작업 절차
1. 이미 조사된 191개 파일 목록을 기반으로 `docs/khi/sound.md` 작성
2. 각 항목에 분위기/스타일과 추천 사용처를 추정 기입 (파일명 기반)
3. 너무 데모 전용이거나 안 쓸 게 명백한 항목은 "(데모용, 비추천)" 표시만 남기고 줄임
4. 작성 후 사용자 확인

## 후속 (선택)
- 작성 후 메모리 인덱스에 "사운드 카탈로그 위치" 메모 추가 제안 — 다음 세션에서 자동 참조 가능
- 프리팹 상황을 받을 때마다 이 파일을 grep해서 매칭

## 핵심 파일
- 입력(조사 완료): TopDownEngine/MMInterface/MMFeedbacks/InventoryEngine/DungeonArchitect_Samples/Unity Timeline 데모 폴더의 모든 `.wav`
- 출력: `client/docs/khi/sound.md`

## 검증
- 파일 작성 후 카테고리별 항목 수 합계가 191개 근처(데모용 제외 시 더 적어도 OK)인지 확인
- 임의 시나리오 1~2개로 테스트: "플레이어 검 휘두름" → 카탈로그에서 KoalaSword1~3 즉시 매칭되는지
