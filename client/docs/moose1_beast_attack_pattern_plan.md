# Moose1 야수형 몬스터 공격 패턴 개선 계획

## 대상

- 프리팹: `Assets/_Project/Prefabs/Enemies/Moose1_Test.prefab`
- 현재 패턴: 근접 접근 후 공격, 근접 공격 이후 원거리 장판 후속 공격
- 개선 방향: 근접 공격과 원거리 장판 공격을 분리하고, 거리 조건에 따라 원거리 장판 3연속 패턴을 사용하도록 변경

## 목표

- 근접 공격은 범위 예고를 유지한다.
- 근접 공격 흐름은 `예고 -> 공격 -> 공격 종료와 동시에 예고 제거`로 정리한다.
- 공격 애니메이션 특정 프레임을 복사해서 강제로 늘린 연출은 제거한다.
- 플레이어가 멀리 있을 때 원거리 장판 공격을 사용한다.
- 원거리 장판 공격은 3연속으로 진행한다.
- 장판 생성 간격은 0.5초로 한다.
- 각 장판은 생성 후 0.7초 뒤 폭발한다.
- 원거리 장판 패턴 쿨타임은 3초로 한다.
- 원거리 패턴이 시작되면 중간에 플레이어가 범위를 벗어나도 3회 생성은 끝까지 진행한다.
- 장판 위치는 플레이어 현재 위치가 아니라 예측 위치를 사용한다.

## 현재 구조 정리

Moose1은 현재 `AIBrain` 상태 기반으로 동작한다.

- `Detecting`
- `Moving`
- `AttackTelegraph`
- `Attack`
- `Recover`

현재 `TelegraphedAreaAttackController`는 근접 공격과 후속 장판 공격을 한 컴포넌트 안에서 처리한다. 이 구조는 간단하지만, 원거리 공격을 독립 패턴으로 운영하기에는 조건 분기와 쿨타임 관리가 애매해진다.

따라서 개선 시에는 근접 공격 컨트롤러와 원거리 장판 컨트롤러의 책임을 분리하는 방향이 적합하다.

## 변경 후 패턴 개요

### 근접 공격

1. 플레이어가 근접 공격 범위 안에 들어온다.
2. Moose1이 근접 공격 예고 상태로 진입한다.
3. 예고 범위가 표시된다.
4. 공격 상태로 진입하면 실제 피해 판정을 처리한다.
5. 공격이 끝나는 시점에 예고 범위를 제거한다.
6. 회복 상태 이후 다시 이동 또는 다음 패턴으로 돌아간다.

### 원거리 장판 공격

1. 플레이어가 근접 범위 밖이고 원거리 공격 가능 거리 안에 있다.
2. 원거리 장판 쿨타임이 준비되어 있으면 패턴을 시작한다.
3. 시작 시점의 거리 조건만 확인한다.
4. 패턴 시작 후에는 플레이어가 범위를 벗어나도 3회 장판 생성을 계속한다.
5. 장판은 0.5초 간격으로 총 3개 생성한다.
6. 각 장판은 생성 시점마다 플레이어 예측 위치를 계산해서 배치한다.
7. 각 장판은 생성 후 0.7초 뒤 폭발한다.
8. 패턴 종료 후 3초 쿨타임을 적용한다.

## AI 상태 설계

권장 상태 흐름은 아래와 같다.

```text
Detecting
  -> Moving
  -> MeleeTelegraph
  -> MeleeAttack
  -> MeleeRecover
  -> Moving

Moving
  -> RangedAreaAttack
  -> RangedAreaRecover
  -> Moving
```

기존 상태명을 유지해야 하는 경우에는 `AttackTelegraph`, `Attack`, `Recover`를 근접 전용으로 두고, 원거리 전용 상태를 추가한다.

```text
RangedAreaAttack
RangedAreaRecover
```

## 전이 우선순위

`Moving` 상태의 전이는 아래 순서로 판단하는 것이 좋다.

1. 타겟이 없거나 죽었으면 `Detecting`
2. 근접 공격 거리 안이면 `AttackTelegraph`
3. 원거리 공격 가능 거리 안이고 쿨타임이 준비됐으면 `RangedAreaAttack`
4. 위 조건이 아니면 계속 추적

근접 공격이 원거리 공격보다 우선되어야 한다. 플레이어가 가까이 있는데 원거리 장판을 쓰면 야수형 몬스터의 압박감이 떨어지고, 근접 패턴이 묻힐 수 있다.

## 원거리 거리 조건 초안

초기값은 아래 정도로 시작하고 플레이 테스트로 조정한다.

- 최소 거리: 3.0
- 최대 거리: 9.0 ~ 11.0
- 쿨타임: 3.0초

최소 거리는 근접 공격 범위보다 충분히 커야 한다. 최대 거리는 현재 맵 크기와 시야/추적 범위를 기준으로 조정한다.

## 예측 위치 계산

장판 위치는 플레이어의 현재 위치에 바로 찍지 않고, 플레이어 이동 방향을 반영한 예측 위치를 사용한다.

```text
predictedPosition = targetPosition + targetVelocity * predictionTime
```

초기 튜닝값:

- `predictionTime`: 0.2 ~ 0.35초

너무 높게 잡으면 플레이어가 방향을 바꿀 때 장판이 지나치게 빗나간다. 너무 낮으면 사실상 현재 위치 공격과 차이가 적다.

## 구현 계획

### 1. 근접 공격 정리

- `TelegraphedAreaAttackController`에서 근접 공격 예고와 실제 판정을 유지한다.
- Moose1 근접 공격용 설정에서 후속 장판 공격 옵션은 제거하거나 비활성화한다.
- 공격 애니메이션을 프레임 복사 방식으로 늘리는 대신, 컨트롤러의 예고 시간/공격 시간/임팩트 타이밍으로 조정한다.
- 공격 종료 시점에 예고 오브젝트가 사라지는지 확인한다.

### 2. 원거리 장판 컨트롤러 추가

신규 컴포넌트 후보:

```text
MooseRangedAreaBarrageController
```

담당 책임:

- 원거리 장판 3연속 패턴 실행
- 0.5초 간격으로 장판 생성
- 각 장판의 0.7초 폭발 지연 처리
- 플레이어 예측 위치 계산
- 패턴 시작 후 중간 취소 없이 3회 완료
- 패턴 종료 후 쿨타임 기록

초기 설정값:

```text
attackCount = 3
spawnInterval = 0.5
detonationDelay = 0.7
cooldown = 3.0
predictionTime = 0.25
areaSize = 2.5 x 2.5
```

### 3. 원거리 전이 결정 추가

신규 결정 컴포넌트 후보:

```text
AIDecisionTargetDistanceBandAndCooldown
```

담당 책임:

- 타겟이 존재하는지 확인
- 타겟이 살아있는지 확인
- 타겟 거리가 최소/최대 거리 안인지 확인
- 원거리 장판 컨트롤러의 쿨타임이 준비됐는지 확인

### 4. Moose1 프리팹 적용

- `Moose1_Test.prefab`의 `AIBrain`에 원거리 상태를 추가한다.
- `Moving` 상태에 원거리 전이를 추가한다.
- 근접 전이가 원거리 전이보다 먼저 평가되도록 배치한다.
- 기존 근접 공격 상태는 유지하되 후속 장판 공격은 제거한다.
- 원거리 컨트롤러를 Moose1 프리팹에 추가하고 초기값을 설정한다.

## 테스트 체크리스트

- 플레이어가 가까우면 근접 공격을 우선 사용한다.
- 근접 공격 예고 범위가 표시된다.
- 근접 공격이 끝나는 시점에 예고 범위가 사라진다.
- 플레이어가 멀리 있으면 원거리 장판 패턴을 사용한다.
- 원거리 장판이 총 3회 생성된다.
- 장판 생성 간격이 0.5초로 동작한다.
- 각 장판이 생성 후 0.7초 뒤 폭발한다.
- 원거리 패턴 시작 후 플레이어가 범위 밖으로 나가도 3회 생성이 끝까지 진행된다.
- 원거리 패턴 종료 후 3초 동안 다시 사용하지 않는다.
- 플레이어가 이동 중일 때 장판이 현재 위치가 아니라 예측 위치 근처에 생성된다.
- 플레이어가 근접 범위로 들어오면 다음 판단부터 근접 공격이 우선된다.
- 추적, 경로 탐색, 장애물 회피 동작과 충돌하지 않는다.

## 추가 아이디어

- 원거리 장판 3회 중 뒤로 갈수록 살짝 더 앞을 예측하게 하면 플레이어가 같은 방향으로 도망갈 때 압박감이 좋아진다.
- 첫 장판은 플레이어 현재 위치에 가깝게, 2~3번째 장판은 예측 위치를 더 강하게 반영하는 방식도 가능하다.
- Moose1이 원거리 장판을 쓰는 동안 짧은 정지 또는 고개 돌림만 허용하면 패턴 가독성이 좋아진다.
- 원거리 장판은 너무 자주 쓰면 피로도가 높으므로, 근접 압박을 보조하는 패턴으로 유지하는 편이 좋다.

## 리스크와 주의사항

- 프리팹 직렬화 파일을 직접 수정할 경우 컴포넌트 참조나 `AIBrain` 전이 순서가 깨질 수 있으므로 Unity 에디터에서 적용하는 방식이 안전하다.
- 원거리 장판이 독립 상태로 분리되면 기존 후속 장판 옵션과 중복 실행되지 않도록 반드시 비활성화해야 한다.
- 예측 시간이 너무 길면 공격이 불합리하게 느껴질 수 있으므로 첫 값은 낮게 잡고 테스트로 올리는 편이 좋다.
- 장판 3연속 패턴은 전투 템포에 큰 영향을 주므로 실제 맵 크기와 회피 공간 기준으로 최대 거리와 범위를 조정해야 한다.
