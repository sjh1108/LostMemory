# CL-051 / CL-052 구현 현황

## 문서 목적

`CL-051 보스 1종 패턴 1 구현`과 `CL-052 보스 1종 패턴 2 및 전조 구현`의 현재 구현 상태를 정리한다.

이 문서는 계획 문서인 `docs/cl051_boss_pattern1_plan.md`, `docs/cl052_boss_pattern2_and_telegraph_plan.md`를 기준으로, 실제로 어떤 런타임/에디터/테스트 자산이 반영되었는지와 현재 완료 범위를 남기는 용도다.

## 대상 스토리

| Jira ID | 범위 | 담당 |
|---|---|---|
| CL-051 | 보스 1종 패턴 1 구현 | 클라2 |
| CL-052 | 보스 1종 패턴 2 및 전조 구현 | 클라2 |

## 구현 방향

- 구현은 외부 에셋 원본 수정 없이 `_Project` 아래의 프로젝트 소유 C# 런타임과 에디터 스크립트 확장으로 진행했다.
- 보스방 입장과 인트로는 `Stage` 계층, Bertha 전투 패턴은 `Enemies/Boss/Bertha` 계층으로 분리했다.
- 전투 구조는 `보스방 입장 -> Entry/Intro -> Encounter 시작 -> AI 상태기 기반 패턴 실행` 흐름으로 정리했다.
- 근접 범위 공격, 대시 공격, 추가 투사체, 피격/사망/임계치 연출을 각각 사이드카 컴포넌트로 나눠 단일 클래스 비대화를 피했다.
- 검증용 씬은 `BossEntryTest`, `BossDoorTest`, `BossTest`를 기준으로 구성했다.

## 구현 결과

### CL-051 보스 인트로 및 전투 시작 흐름

- `BossIntroSequenceData`, `BossIntroSequenceController`, `BossRoomEncounterStarter`를 추가해 보스방 입장 후 플레이어 잠금, Entry 재생, 대사 훅, 전투 시작 타이밍을 분리했다.
- `BerthaBossEncounterController`를 추가해 인트로 전에는 전투용 브레인/행동을 비활성화하고, 인트로 종료 후에만 전투를 시작하도록 구성했다.
- `BerthaAnimationSetupEditor`를 추가해 Bertha용 `Idle`, `Walk`, `Entry` 기반 Animator 생성 흐름을 만들었다.
- `BerthaBrainAnimationController`를 추가해 AI 상태와 애니메이션 상태를 동기화하도록 구성했다.

### CL-051 첫 전투 루프 및 대시 패턴 기반

- `BerthaDashPatternBootstrap`, `BerthaDashStartAction`, `BerthaDashHitGate`, `BerthaDashAttackController`를 추가해 대시 전조, 돌진 시작, 충돌 피해, 대시 공격 타이밍을 분리했다.
- `BerthaLightAttack1Bootstrap` 중심의 통합 상태기 구성으로 `Detecting`, `Moving`, `Telegraph`, `Dash`, `Recover` 축을 정리했다.
- `AttackTelegraph2DView`, `AIBrainDashTelegraphDriver`와 연결해 돌진 전조를 시각적으로 확인할 수 있게 했다.
- `BossTest.unity`를 통해 Bertha 전투 패턴 수동 검증용 씬 구성을 추가했다.

### CL-052 패턴 2 확장

- `BerthaAreaAttackController` 기반으로 `LightAttack1`, `LightAttack2`, `HeavyAttack`, `FullCombo`의 범위형 공격 루프를 구성했다.
- `BerthaCombatPatternSelector`를 추가해 거리, 체력 조건, 쿨다운, 가중치에 따라 패턴을 선택하도록 구현했다.
- 공격 타격 타이밍을 직렬화 값으로 조절 가능하게 정리했고, 대시/일반 공격의 타이밍을 런타임에서 별도 조정 가능하게 했다.
- 보스가 공격 후 사라지던 문제를 수정하고, 보스 레이어 우선순위도 보정했다.

### CL-052 강공격 및 풀콤보 투사체 확장

- `BerthaBossProjectile`를 추가해 직선 이동, 수명, 단일 피격 처리를 담당하도록 구현했다.
- `BerthaProjectileBurstEmitter`를 추가해 radial/fan 형태의 다발 발사를 지원하도록 구성했다.
- `BerthaProjectilePatternDriver`를 추가해 특정 공격 상태에서 지정 타이밍에 burst를 발사하도록 연결했다.
- 강공격에는 `8방향 radial burst`를 1회 연결했다.
- 풀콤보에는 `fan burst 2회 + radial burst 1회` 구조를 연결했다.
- 보스 투사체가 `Obstacles` 레이어 벽에 닿으면 즉시 소멸하도록 처리했다.

### CL-052 피격, 사망, 임계치 연출 보강

- `BerthaHitReactionPresenter`를 추가해 피격 시 붉은 플래시, 흔들림, 스케일 펀치가 재생되도록 구현했다.
- 대시 및 dash 계열 상태에서는 피격 반응 강도를 추가로 높이도록 보정했다.
- `BerthaAnimationSetupEditor`를 확장해 `Death`, `Tired`, `ToStun`, `Stuned`, `ShakeHead`, `OutStun` 클립 생성과 컨트롤러 연결을 지원하도록 했다.
- 사망 시 모델이 바로 꺼지지 않고 시체가 맵에 남도록 `Health` 설정을 조정했다.
- `BerthaHealthThresholdReactionController`를 추가해 체력 임계치 기반 연출을 구현했다.
  - 체력 `70% 이하` 진입 시 `ToStun -> Stuned -> ShakeHead -> OutStun`
  - 체력 `30% 이하` 진입 시 `Tired`
- 임계치 연출은 단순 Animator 전환이 아니라 `Entry`처럼 AI와 이동을 잠시 멈춘 뒤 재생 후 복귀하도록 구성했다.
- `ShakeHead`는 약 5초 유지되도록 했고, `ToStun`, `OutStun`은 더 느리게 재생되도록 조정했다.

## 현재 검증 상태

이 문서 작성 시점 기준으로 전용 테스트 씬과 런타임 구성은 존재하지만, 현재 CLI 환경에서는 Unity 배치 컴파일과 플레이모드 실행 검증을 재수행하지 못했다.

따라서 아래는 `구현 반영 여부`와 `검증 자산 존재 여부` 기준의 상태다.

- `BossEntryTest`, `BossDoorTest`, `BossTest` 씬 자산 존재
- Bertha용 Animator/Animation 생성 에디터 메뉴 존재
- Bertha 전투/투사체/피격/사망/임계치 반응 런타임 스크립트 존재
- Unity 에디터 내 최종 수동 검증은 별도로 필요
