# 메타 성장

## 목표

런 외부 성장과 런 내부 성장을 분리하되, 반복 플레이 동기가 기억 수집, 무기 해금, 스토리 해금으로 자연스럽게 이어지게 만든다.

## 성장 축

1. 런 내부 성장 (던전에서 성장)
- 유물/보상 선택
- 상점 구매
- 큰방 공략 중 체감되는 즉시형 성장
- 런 종료 시 모두 소멸

2. 런 외부 성장 (마을에서 성장)
- 기억 시스템 진행
- 기억의 파편 기반 기억의 조각 활성화
- 무기 해금 및 강화 단계 해금
- 재능 시스템 진행
- 단편 기억 스토리 해금

## 기억 시스템 개요

- 기억의 파편은 보스 격파 또는 한 판 종료 보상으로 얻는 메타 재화다
- 기억의 파편을 소모해 기억의 조각을 생성한다
- 기억의 조각을 모아 메인 기억 퍼즐을 완성한다
- 메인 기억은 총 4개를 기준으로 잡고, 각 메인 기억마다 단편 기억 스토리와 무기 해금을 연결한다

## 기억 용어 정리

| 용어 | 정의 |
|---|---|
| 기억의 파편 | 보스 격파/런 종료 보상으로 얻는 메타 재화 |
| 기억의 조각 | 기억의 파편으로 생성하는 퍼즐 조각 단위 |
| 메인 기억 | 하나의 큰 퍼즐 완성 단위 |

## 기억 진행 흐름

- 보스 격파 또는 런 종료 시 기억의 파편을 획득한다
- 기억의 파편을 사용해 기억의 조각을 생성한다
- 생성한 기억의 조각을 퍼즐에 배치한다
- 필요한 조각을 모두 맞추면 메인 기억 하나가 완성된다
- 기억의 파편은 기억의 조각 생성뿐 아니라 각인 강화 재화로도 사용한다

## 메인 기억 구조

- 메인 기억은 하나의 큰 퍼즐로 표현한다
- 퍼즐의 요구 크기는 `1 x 1 -> 2 x 2 -> 4 x 4` 순으로 확장한다
- 총 4개의 메인 기억 전체에 어떤 크기를 어떻게 배분할지는 밸런스 테스트 후 확정한다
- 퍼즐 완성 시 완성된 기억 이미지를 약 3초간 보여주고 다음 화면으로 넘긴다

## 기억의 조각 효과 방향

- 재능 포인트 부여
- 시작 시 포션 지급
- 대시 횟수 추가
- 대시 쿨타임 감소
- 대시 무적 시간 증가
- 최대 체력 증가
- 레벨업 시 회복 체력 증가

## 재능 강화 효과 방향

- 치명타 확률
- 공격 속도
- 방어력
- 마나 회복
- 최대 체력

기준안:
- 재능 강화를 위해서 기억의 파편을 사용해 재능 포인트를 주는 기억의 조각을 완성해야 한다.
- 1차 밸런스는 세피리아 레퍼런스 기준으로 최대 20포인트 수준을 우선 검토한다
- 확장 난이도 또는 정식판에서는 최대 30포인트까지 확장 가능성을 열어둔다

## 재화 구조

- 기억의 파편
- 재능 포인트
- 런 내부 상점 재화

## 권장 설계 원칙

- 런 외부 성장은 기억 퍼즐과 기본 능력치 강화 위주로 단순하게 유지한다
- 공격력, 체력, 기동성, 생존 등 직관적인 능력치 중심으로 설계한다
- 지나치게 복잡한 다중 트리 구조는 지양하고, 기억 퍼즐 자체가 빌드 서사를 담당하게 한다
- 협동 플레이에서 스토리 진행 기준은 `파티원 중 가장 스토리가 덜 진행된 플레이어`에 맞춘다
- 상위 진행도 플레이어는 낮은 진행도 플레이어의 단편 기억 또는 메인 기억 해금 순서를 건너뛰게 만들지 않는다

## 협동 플레이 시 스토리 동기화 원칙

- 파티 진입 가능 범위는 파티원 중 최저 스토리 진행도 기준으로 결정한다
- 스토리 연출, 메인 기억 개방, 단편 기억 노출 기준도 최저 진행도 기준으로 맞춘다
- 런 보상, 기억의 파편 지급, 계정 저장은 각 플레이어 계정에 개별 저장한다
- 상위 진행도 플레이어는 낮은 진행도 기준 방에 입장할 수 있지만, 반대로 낮은 진행도 플레이어가 잠기지 않은 스토리를 선행 해금하지는 않는다

## 무기 성장 방향

- 무기 후보는 검, 망치, 칼, 활을 기준으로 확장한다
- 무기 강화는 런 중 선택형 강화보다 마을에서 기억 조각 활성화를 통해 단계 해금하는 구조를 우선한다.
- 플레이어는 해금한 강화 단계 중 하나를 선택한 뒤 런에 진입한다
- 각 메인 기억 완성은 대응하는 무기 또는 강화 단계 해금과 연결하는 방향을 검토한다
- 초반에는 무기별 역할 차이를 우선하고, 티어 구조는 단순하게 유지한다

## 현재 미정 사항

- 메인 기억 4개의 구체 테마와 서사 배치
- 기억의 조각 생성 규칙과 중복 처리 방식
- 기억의 파편 획득량/소모량 공식
- 무기 해금에 기억 완성과 별도 재화를 모두 요구할지 여부
