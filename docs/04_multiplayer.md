# 멀티플레이 규칙

## 목표

온라인 협동을 넣되 구조는 단순하게 유지한다. 복잡한 매칭보다 함께 안정적으로 한 판을 끝내는 경험을 우선한다.

## 기본 구조

- 1~4인 온라인 협동
- 호스트 기반 진행
- 방장이 세션 생성 및 게임 시작 담당

## 세션 규칙

- 호스트가 게임 상태 진행 기준
- 참가자는 방 코드 또는 초대 방식으로 입장
- MVP에서는 자동 매칭 미포함

## 전투/진행 규칙

- 아이템 및 보상은 개인 드랍/개인 선택
- 방의 적을 모두 처치해야 다음 방 진입 가능
- 보스방은 선행 전투를 모두 클리어해야 입장 가능
- 전원 상호작용 시 다음 방 이동 권장

## 다운/전멸 규칙

- 생존 플레이어가 있으면 다운 상태 가능
- 전원 다운 또는 전원 사망 시 패배

## 호스트 이탈 처리

MVP 기준:
- 호스트 이탈 시 세션 종료

## 재접속 정책

우선순위 낮음.

권장안:
- MVP에서는 미지원
- 확장 시 세션 유지 중인 경우 스테이지 시작 지점으로 재합류 검토

## 현재 확정 사항

- 호스트 기반
- 개인 드랍
- 온라인 협동 포함

## 현재 미정 사항

- 방 코드 방식 상세
- 로비 준비 상태 처리 방식
- 네트워크 솔루션 최종 선택
