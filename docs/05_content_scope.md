# 콘텐츠 범위

## 목표

콘텐츠 수를 과도하게 늘리지 않고, 적은 수의 전투 요소를 조합해 반복 플레이 재미를 만든다.

## MVP 권장 수량

- 무기: 검 1종 우선, 여유 시 1종 추가
- 일반 적: 3종
- 엘리트 적: 1종
- 보스: 1종
- 전투방 프리팹: 4~6종
- 상점방: 1종
- 이벤트방: 2종
- 보상/유물: 10종 우선, 확장 시 15~20개

## 확장 목표 수량

- 무기: 검 / 망치 / 칼 / 활
- 일반 적: 4종
- 엘리트 적: 2종
- 보스: 2종 이상
- 전투방 프리팹: 8종 이상
- 보상/유물: 25~30개

## 무기군 확장 방향

| 무기 | 역할 | 핵심 키워드 |
|---|---|---|
| 검 | 표준형 | 3타 연계, 패링, 안정적인 밸런스 |
| 망치 | 중량형 | 느린 공격, 강한 경직, 높은 순간 피해 |
| 칼 | 고속형 | 짧은 리치, 연타, 대시 연계 |
| 활 | 원거리형 | 거리 유지, 투사체 운용, 안전한 견제 |

## 유물 카테고리

- 공격형
- 생존형
- 방어형
- 기동형
- 돈/행운형

## 비유물 보상

| 이름 | 종류 | 효과 |
|---|---|---|
| 작은 회복약 | 비유물 | 체력 `25%` 회복 |
| 큰 회복약 | 비유물 | 체력 `50%` 회복 |
| 랜덤 박스 | 비유물 | 보유하지 않은 랜덤 유물 1개 획득 |

## 보상 규칙

- 기본 보상은 유물 3개 중 1개 선택
- 드물게 비유물 보상 테이블이 개입
- 유물은 런 전용이다
- 유물은 중복 획득할 수 없다
- 모든 유물은 공용 유물로 설계한다
- 비유물 보상은 `작은 회복약`, `큰 회복약`, `랜덤 박스`를 사용한다

## 상점 구성 초안

- 판매 슬롯은 아이템 3종과 포션 1종을 기본안으로 잡는다
- 아이템은 유물, 소비형 아이템, 특수 구매 옵션 중에서 구성한다
- 피해를 적게 받는 플레이가 상점 투자 효율로 이어지게 설계한다

## 랜덤 박스 규칙

- 랜덤 박스는 현재 보유하지 않은 유물 중 무작위 1개를 즉시 획득한다
- 이미 보유한 유물은 후보에서 제외한다
- 유물 등급은 별도 확률 테이블을 따른다
- 후보 유물이 부족하거나 없을 경우 `큰 회복약`으로 대체한다
- 랜덤 박스로 획득한 유물은 즉시 효과가 적용된다

## 적 역할 초안

- 근접형: 기본 추적 및 근접 공격
- 돌진형: 플레이어를 보면 돌진 패턴 사용
- 원거리형: 거리 유지 후 투사체 공격
- 엘리트형: 상위 패턴 및 체력 증가

## 보스 설계 원칙

- 패턴은 읽기 쉬워야 함
- 패링 가능한 공격과 대시로 피해야 하는 공격을 분리
- MVP는 2페이즈
- 최종 보스 확장 시 3페이즈 검토

## 현재 미정 사항

- 챕터 수 최종 목표
- 적별 구체 패턴 수
- 무기 스킬 구성
- 이벤트방 등장 확률
- 상점 판매군 비율
