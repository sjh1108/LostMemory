# 전투 시스템

## 목표

짧은 시간 안에 액션 손맛과 읽을 수 있는 패턴, 협동 플레이의 재미를 동시에 보여준다.

## 플레이어 기본 액션

- 기본 공격
- 대시
- 패링
- 다운/부활

## 기본 공격 설계 방향

- 짧은 연계 중심
- 과도한 장기 콤보는 지양
- 1~2타 이후 대시 캔슬 가능
- 마지막 타에 추가 효과 부여 가능

권장안:
- 기본 3타 연계
- 3타째 강화 효과
- 무기 고등급화 시 연계 길이 증가보다 조건부 강화 효과 추가

예시:
- 3타째 충격파
- 패링 후 다음 공격 강화
- 대시 후 첫 공격 강화

## 대시

- 생존과 포지셔닝의 핵심 수단
- 짧은 무적 시간을 포함하는 기본안으로 확정하고, 실제 시간 수치만 테스트로 조정한다

## 패링

- MVP 기준 `방향 없는 타이밍 패링`을 사용한다
- 타이밍 맞춰 입력하면 공격 무효화
- 성공 시 적 경직 또는 밀려남
- 일부 적/보스 패턴에 핵심 카운터 수단으로 사용

## 피격 경직 권장안

- 플레이어: 일반 공격에는 아주 짧은 경직 또는 없음
- 플레이어: 강공격/엘리트/보스 패턴에는 명확한 경직
- 적: 일반 몬스터는 가벼운 피격 반응
- 엘리트/보스: 일부 슈퍼아머 보유

## 다운/부활

- 협동 시 생존자가 1명 이상이면 다운 상태 진입
- 다운 후 약 10초 안에 아군이 상호작용하면 딸피로 부활
- 솔로 플레이 시 즉시 패배 처리

## 무기 역할 초안

- 검: 표준형, 밸런스형
- 창: 긴 사거리, 찌르기 중심
- 활: 원거리 견제형
- 확장 후보: 해머, 쌍검

MVP 우선순위:
- 검 먼저 구현
- 이후 창 또는 활 추가

## 타격감 기준

- 짧은 히트스톱
- 강한 타격에는 더 긴 히트스톱
- 타격 플래시
- 적 피격 반응
- 패링 성공 시 확실한 효과음/연출
- 카메라 흔들림은 약하게

## 현재 미정 사항

- 무기별 스킬 개수
- 치명타 시스템 유무
- 상태이상 종류
