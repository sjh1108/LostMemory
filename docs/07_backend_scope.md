# 백엔드 범위

## 목표

실시간 전투 서버를 직접 구현하지 않고, 계정/저장/기록 등 서비스성 기능을 담당한다.

## 서버팀 담당 범위

- 로그인
- 유저 데이터 저장
- 랭킹

## 권장 세부 기능

- 게스트 또는 간단 계정 로그인
- 닉네임/프로필 조회
- 무기 해금 상태 저장
- 영구 강화 수치 저장
- 런 종료 결과 저장
- 클리어 기록 및 랭킹 조회

## 비범위

- 실시간 이동 동기화
- 실시간 전투 판정
- 몬스터 AI 시뮬레이션
- authoritative game server

## 클라이언트와의 연동 시점

- 로그인 시
- 로비 진입 시
- 런 종료 시
- 결과 저장 및 랭킹 조회 시

## 추천 API 초안

- POST /auth/login
- GET /users/me
- PUT /users/me
- GET /progression
- PUT /progression
- POST /runs/result
- GET /rankings

## 현재 미정 사항

- 인증 방식
- 게스트 로그인 지원 여부
- 관리자 페이지 필요 여부
