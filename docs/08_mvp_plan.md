# MVP 계획

## 목표

스테이지 수를 줄이더라도 전투와 보스전의 완성도를 높여, 짧게 플레이해도 재미가 느껴지는 데모를 만든다.

## MVP 핵심 원칙

- 양보다 전투의 정성적 완성도
- 온라인 협동 최소 버전 포함
- 보스전과 빌드 선택의 손맛 강조

## MVP 필수 요소

- 검 1종
- 일반 적 3종
- 엘리트 1종
- 보스 1종
- 큰방 4개
- 작은방 5개 구조 1세트 검증
- 상점방 1개
- 이벤트방 1~2개
- 유물 10종 우선
- 기억 시스템 최소 버전 1세트
- 온라인 협동 최소 2인 안정화

## 단계적 구현 권장

1차:
- 검 전투 루프 완성
- 큰방/작은방 구조 검증
- 유물 10종과 상점 기본안 적용
- 기억의 파편 지급 -> 기억의 조각 생성 -> 메인 기억 1개 완성 흐름 검증

2차:
- 메인 기억 4개 구조 확장
- 무기 해금과 모루 시스템 연결
- 유물 15~20개 확장
- 상점과 이벤트방 다양화

## 만들면 좋은 요소

- 망치, 칼, 활 중 1종 추가
- 보스 2종
- 이벤트방 추가
- 4인 안정화
- 랭킹 화면 고도화

## 이번 단계에서 제외 권장

- 재접속 복구
- 자동 매칭
- 복잡한 스토리
- 여러 챕터 동시 제작
- 캐릭터 여러 명
- 복잡한 스킬 트리
- 기억 시스템의 전체 시네마틱 연출

## 정성적 목표

- 공격이 맞을 때 시원해야 한다
- 패링 성공이 눈에 띄게 기분 좋아야 한다
- 보상 3택을 고르는 재미가 있어야 한다
- 협동 플레이에서 부활/지원이 의미 있어야 한다
- 기억 수집이 다음 판 동기로 연결되어야 한다

## 회의용 체크리스트

- 플레이타임 13분 전후 확정
- 검 전투 루프 먼저 완성
- 유물 1차 목록 확정
- 보스 1종 패턴 확정
- 온라인 2인 안정화 목표 확정
- 서버 API 범위 확정
- 기억 시스템 1차 UX 범위 확정
