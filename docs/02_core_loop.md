# 코어 루프

## 목표

한 판이 짧고 선명하게 느껴지는 구조를 만든다. 설명이 길지 않아도 플레이 자체로 이해 가능한 흐름을 지향한다.

## 기본 흐름

로비 -> 캐릭터/스킨 선택 -> 무기 선택 -> 큰방 1 -> 보상 선택 -> 큰방 2 -> 보상 선택 -> 상점/회복 -> 큰방 3 -> 보상 선택 -> 큰방 4 -> 보상 선택 -> 보스 -> 결과/기억의 파편 획득 -> 영구 성장

## 1챕터 기준 흐름

- 큰방
- 큰방
- 상점방
- 큰방
- 큰방
- 보스방

현재 기준:
- 큰방 4개
- 상점방 1개
- 보스방 1개

조정 가능 항목:
- 큰방 개수는 테스트 결과에 따라 증감 가능
- 상점방과 보스방은 고정 유지

## 스테이지 구조 상세

- 하나의 큰방은 작은방 5개로 구성한다
- 플레이어는 작은방의 탈출구에 도달하면 다음 작은방으로 이동한다
- 작은방 내부의 적을 모두 처치하기 전까지는 탈출할 수 없다
- 큰방 1개를 모두 돌파하면 그 시점에 보상 선택 1회를 제공한다

## 상점 구성 초안

- 상점에서는 아이템 3종과 포션 1종을 돈으로 구매할 수 있다
- 회복을 아끼면 포션 대신 빌드 아이템에 더 투자할 수 있게 설계한다
- 상점은 런의 중간 완충 구간이자 다음 큰방을 준비하는 선택 지점으로 사용한다

## 보스방 역할

- 보스방에는 해당 챕터의 보스가 존재한다
- 보스를 처치하면 해당 단계가 종료되고 결과 화면으로 넘어간다
- 기억의 파편은 기본적으로 보스 격파 또는 한 판 종료 보상 기준으로 지급한다

## 이벤트방 처리

이벤트는 별도 필수 방이 아니라 일정 확률로 기존 흐름 일부를 대체한다.

예시:
- 축복 이벤트: 체력 회복 또는 랜덤 유물 획득
- 도박 이벤트: 체력 일부 소모 후 고등급 보상 획득
- 대장간 이벤트: 무기 강화 또는 보상 재선택

MVP 기준:
- 이벤트 종류 2종
- 전투 흐름을 끊지 않는 짧은 선택형 이벤트 중심

## 1판 플레이타임 목표

- 큰방 1개당 약 2분 내외
- 보스전 약 5분
- 챕터 총 플레이타임 약 13분

## 런 종료 보상

- 영구 강화 재화 지급
- 기억의 파편 지급
- 무기 해금/모루 재화 지급 검토
- 런 내부 재화는 소멸

## 현재 확정 사항

- 보상은 3개 중 1개 선택
- 상점에서 회복 또는 구매 가능
- 실패해도 영구 성장 자원은 일부 획득
- 1챕터는 큰방 4개 + 상점 1개 + 보스 1개 구조를 기준으로 설계한다
- 큰방은 작은방 5개를 연속 클리어하는 구조를 사용한다

## 현재 미정 사항

- 챕터별 분기 여부
- 런 실패 시 지급량 공식
- 상점 상품 구성 비율
- 큰방/작은방 최종 수량
