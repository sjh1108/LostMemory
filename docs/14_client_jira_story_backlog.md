# 클라이언트 지라 스토리 목록

## 문서 목적

클라이언트 세부 계획을 기준으로 Jira에 바로 등록할 수 있는 스토리 목록을 정리한다.  
프로젝트 키는 아직 정해지지 않았으므로 임시 식별자는 `CL-###` 형식으로 둔다.

## 운용 기준

- 에픽은 기능 축 기준으로 나눈다
- 스토리는 1명 기준 1~3일 내 완료 가능한 단위로 쪼갠다
- 기술 검증과 문서화도 별도 스토리로 등록한다
- `스토리 동기화는 파티 내 최저 진행도 기준` 정책을 전제한다
